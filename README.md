# HexStrike + ScanX — Automated Security Assessment CLI

HexStrike + ScanX is a **CLI-first security assessment orchestrator**. It starts with service discovery, adapts the next scanner stages to what was discovered, normalizes and correlates evidence, calculates a risk level, and prints actionable remediation guidance directly in the terminal.

> Use only on systems you own or are explicitly authorized to assess. The project does not provide arbitrary shell execution.

## What is included

- Nmap discovery and service/version detection
- ScanX adapter with configurable `SCANX_BIN`
- Nikto, Nuclei, WhatWeb, httpx, Gobuster, FFUF
- Amass and Subfinder for domain targets
- Scanner health/doctor checks
- Adaptive multi-scanner orchestration
- Concurrent independent web/domain stages
- Normalized findings and cross-scanner correlation
- Confidence scoring and deterministic risk scoring
- Asset inventory and attack-surface summary
- Remediation recommendations with verification steps
- Persistent JSON evidence/history
- Optional local Ollama/Gemma analysis (`hexstrike assess TARGET --ai`)
- MCP server for tool-oriented AI clients
- Optional JSON/HTML export; **no report is generated by normal `assess`**
- Configuration validation and CI tests

## One-command workflow

```bash
hexstrike assess TARGET
```

Example lab target:

```bash
hexstrike assess 192.168.56.101
```

The example target is not hard-coded and is not required.

## Installation

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell
# .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
pip install -e .
hexstrike doctor
```

Install whichever external scanners you want available in your environment. The engine reports unavailable tools and continues rather than crashing.

## CLI

```text
hexstrike health
hexstrike doctor
hexstrike self-test
hexstrike config validate
hexstrike config profiles
hexstrike config show aggressive
hexstrike scanner list
hexstrike scanner health
hexstrike assess <target> [--profile aggressive] [--ai] [--json]
hexstrike scan <scanner> <target>
hexstrike scan run <scanner> <target>
hexstrike scan status <scan_id>
hexstrike scan results <scan_id>
hexstrike findings list [record_id]
hexstrike findings show <finding_id>
hexstrike analyze <record_id>
hexstrike history [--limit N]
hexstrike export <record_id> --format json|html --output PATH
hexstrike mcp start
```

## Adaptive pipeline

```text
TARGET
  ↓
Target normalization
  ↓
NMAP discovery
  ├── web ports → httpx / WhatWeb / Nikto / Nuclei
  │              └→ Gobuster / FFUF when a wordlist is configured
  ├── domain → Amass / Subfinder
  └── network → ScanX adapter
  ↓
Finding normalization
  ↓
Correlation + confidence
  ↓
Asset inventory + attack surface
  ↓
Risk + recommendations
  ↓
Terminal output + persistent evidence
```

## ScanX integration note

ScanX is intentionally treated as an adapter contract because different ScanX distributions expose different command-line interfaces. Set `SCANX_BIN` to the correct local executable. Do not assume an upstream CLI syntax that has not been verified in your installation.

## Optional Ollama

If Ollama is running locally, install/pull the model you want and set:

```bash
set HEXSTRIKE_OLLAMA_MODEL=gemma3:4b
```

or on Linux/macOS:

```bash
export HEXSTRIKE_OLLAMA_MODEL=gemma3:4b
```

Then:

```bash
hexstrike assess TARGET --ai
```

The scanner pipeline does not depend on Ollama.

## Status

This repository is the **complete CLI-oriented project package for the implemented phases**. External scanner binaries remain environment dependencies, and ScanX CLI syntax remains configurable by design.

### Final verification

`hexstrike self-test` runs deterministic internal checks without invoking external scanners. `hexstrike doctor` verifies configuration and reports the availability of external scanner binaries.
